Pick a state and a time window on the left, then run a scan. Reports of drivers striking cyclists land here, newest first, and stay logged so repeat scans build up a running record.

Results come straight from Google News search, filtered to your state and time window — this page doesn't use any paid API and doesn't invent stories. Headlines are matched by keyword, not read for meaning, so occasional off-target results are normal; skim before treating anything as a confirmed case. Google News's free search leans toward recent, prominent coverage rather than acting as a complete historical archive, so even a "1 year" scan will mostly surface currently-findable stories, not every matching crash ever reported — treat the count as "what's findable right now," not a census. Very recent windows (like 1 day) sometimes return little for the same reason. State filtering only works precisely for stories found during a scan run with that state selected — stories found under "All states" are tagged generically and won't reappear if you switch to a specific state later. Your log is saved in this browser once the page is hosted on its own; it won't carry over to a different browser or device.
